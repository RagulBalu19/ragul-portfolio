React ES6

Handwritten class notes on ES6 concepts used in React including Classes, Constructor and Methods.

August 30, 2026 5 min read

ES6 (ECMAScript 6) is the sixth version of JavaScript and introduces many modern features that are widely used in React development.

ES6

  • ES6 → ECMAScript 6
  • ES6 → 6th version of ECMAScript
  • Published in 2015 (ECMAScript 2015)

Why Should Learn ES6

React uses ES6. We should be familiar with the following features:

  • Classes
  • Arrow Function
  • Variables (let, const, var)
  • Array Methods (.map())
  • Destructuring
  • Modules
  • Ternary Operator
  • Spread Operator

React ES6 Classes

Classes

  • ES6 introduced Classes.
  • Class is a type of function.
  • Instead of using the keyword function, we use the class keyword.
  • We must use the class keyword.
  • The properties are assigned inside the constructor() method.

Example : Simple Class 

class Car {

    constructor(name) {
        this.brand = name;
    }

}

We have begun the class name "Car" with an uppercase letter. This is the standard naming convention for classes.

Example : Create Object 

class Car {

    constructor(name) {
        this.brand = name;
    }

}

const myCar = new Car("Hyndai");

The constructor function is called automatically when the object is initialized.

Method in Class 

class Car {

    constructor(name) {
        this.brand = name;
    }

    Present() {
        return "I have a " + this.brand;
    }

}

const myCar = new Car("Hyndai");

myCar.Present();

The above example showcases, we call the method by referring to the object's method name followed by parentheses. Parameters would go inside the parentheses.
