React ES6 - Class Inheritance & Arrow Functions

Handwritten notes covering ES6 Class Inheritance, super() method and Arrow Functions.

August 31, 2026 6 min read

ES6 supports class inheritance using the extends keyword. It also introduces Arrow Functions, which provide a shorter syntax for writing functions.

Class Inheritance

  • To create class inheritance, use the extends keyword.
  • A class created with inheritance inherits all the methods from another class.

Example : Create Class Inheritance 

class Car {

    constructor(name) {
        this.brand = name;
    }

    Present() {
        return "I have a " + this.brand;
    }

}

class Model extends Car {

    constructor(name, mod) {
        super(name);
        this.model = mod;
    }

    Show() {
        return this.Present() + ", it is a " + this.model;
    }

}

const myCar = new Model("Ford", "Mustang");

myCar.Show();

The super() method refers to the parent class.

By calling super() inside the constructor, we call the parent's constructor method and get access to the parent's properties and methods.

React ES6 Arrow Functions

Arrow functions allow us to write a shorter function.

Example 

hello = () => {
    return "Hello World!";
}

If the function has only one statement, we don't need to write the return keyword. 

hello = () => "Hello Bro!";

This works only when one statement is available to print.

Parameters

If we have parameters, pass them inside the parentheses. 

hello = (val) => "Hello " + val;

If we have only one parameter, we can avoid parentheses. 

hello = val => "Hello " + val;

What About this?

Compared to regular functions, handling of this in arrow functions is different.

  • There is no binding of this in arrow functions.
  • In regular functions, this represents the object that called the function (window, document, button or whatever).
  • In arrow functions, this represents only the object that defined the arrow function.
