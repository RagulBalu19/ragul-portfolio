React ES6

Handwritten class notes on ES6 concepts used in React including Variables and Array map().

September 01, 2026 7 min read

ES6 introduced new ways to declare variables and powerful array methods like map(). These features make JavaScript code cleaner, safer, and are widely used in modern React applications.

React ES6 Variables

Before ES6, variables were declared using only the var keyword.

  • Before ES6, variables were declared only using var.
  • If a variable was not properly declared, it could become part of the global object.

ES6 introduced three different variable declaration keywords:

  • var
  • let
  • const

var Keyword 

var x = 5.6;
  • If var is declared outside a function, it belongs to the global scope.
  • If declared inside a function, it belongs to that function.
  • If declared inside a block (for example, a for loop), the variable is still accessible outside the block.

Important

var has function scope, not block scope.

let Keyword 

let x = 5.6;
  • let is the block-scoped version of var.
  • Variables declared using let are available only inside the block where they are defined.
  • If declared inside a loop or conditional block, they cannot be accessed outside the block.

Important

let has block scope.

const Keyword 

const x = 5.6;

The const keyword declares a variable whose reference cannot be reassigned.

Important

  • const has block scope.
  • It creates a constant reference, not a constant value.
  • You cannot reassign a constant value, array, or object.
  • You can modify elements inside a constant array.
  • You can modify properties of a constant object.

React ES6 Array map()

The map() method creates a new array by calling a function for every element in an existing array.

Example : Multiply Each Number by 2 

const num = [1, 2, 3, 4];

const double = num.map(x => x * 2);

// Output
// [2, 4, 6, 8]

The above example creates a new array by multiplying every number by 2.

map() in React

The map() method is commonly used in React to render a list of elements.

Example 

const fruits = ["Apple", "Orange", "Papaya"];

function MyFruit() {

    return (

        <ul>

            {fruits.map((fruit) => (
                <li key={fruit}>{fruit}</li>
            ))}

        </ul>

    );

}

Output:

  • Apple
  • Orange
  • Papaya

Important

When using map() in React to render a list, every list item should have a unique key prop.
