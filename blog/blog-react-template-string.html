React ES6 - Template String

Handwritten class notes on ES6 Template Strings, multiline strings, expression interpolation, variable insertion, map(), and ternary operator.

September 08, 2026 6 min read

Template strings allow us to write multiple lines and expressions inside a string.

React ES6 Template String

It allows to write multiple lines and expressions.

Example 

const name = "John";
    const age = 20;

    const msg = `Hello, ${name}.
    You are ${age} old!`;

Template String

Template strings use backticks (`) instead of quotes and include:

  • Multiple lines without \n
  • Expressions inside ${}
  • Quotes without escaping

Example : Multi-lines 

const html = `

        
Title

        
Para

    
`;

The indentation in multiline string become part of string.

Expression Interpolation

We can include any valid JS expression inside ${}.

Example : Variable Insert 

const FN = "John";
    const LN = "Doe";

    console.log(`Welcome ${FN} ${LN}`);

Example : Expression Insert 

const a = 10;
    const b = 10;

    const c = `total: ${a + b}`;

Example : Using map() 

const items = ["a", "b", "c"];

    const list = `We have ${items.length} items:
    ${items.map(item => `${item}`).join(", ")}`;

Example : Ternary Operator Insert 

const active = true;

    const msg = `Status: ${active ? 'admin' : 'user'}`;
