React ES6 - Spread Operator & Modules

Handwritten class notes on the ES6 Spread Operator, Destructuring with Spread, Modules, Named Exports, Default Exports and Import.

September 05, 2026 6 min read

React ES6 Spread Operator

The JavaScript spread operator (...) copies all or part of an existing array or object into a new array or object.

Example 

const n1 = [1, 2, 3];

const n2 = [4, 5, 6];

const n3 = [...n1, ...n2];

// [1, 2, 3, 4, 5, 6]

Destructuring and Spread Operator

We can use both destructuring and spread operator at the same time. 

const numbers = [1, 2, 3, 4, 5];

const [one, two, ...rest] = numbers;

// 1
// 2
// 3, 4, 5

Spread Operator with Object 

const car = {
    brand: "Ford",
    model: "Mustang",
    color: "red"
};

const car2 = {
    type: "car",
    year: 2021,
    color: "white"
};

const myCar = {...car, ...car2};

console.log(myCar);

React ES6 Modules

JS modules break a code into separate file. This make it easier to maintain code-base.

ES6 use import and export statement to use modules.

Export

We can export function or variable from any file.

There are 2 types of exports:

  • Named Exports
  • Default Exports

Named Exports

There are 2 ways to create named export:

  1. Inline individually
  2. All at once at the bottom

Example 1 

export const name = "John";

export const age = 20;

Example 2 

const name = "John";

const age = 20;

export { name, age };

Default Exports

We have only one default export in a file.

Example 

const msg = () => {
    const name = "John";
    const age = 20;

    return name + " is " + age + " old";
};

export default msg;

Import

We can import files in two ways, based on named export or default export.

Example : Import Named Export 

import { name, age } from "./person.js";

Example : Import Default Export 

import msg from "./msg.js";
