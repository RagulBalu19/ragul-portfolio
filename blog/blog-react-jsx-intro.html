React JSX

Handwritten class notes on JSX including Coding JSX, Expressions, Multiple-line HTML, Top Level Elements, Fragments, Closed Elements, className and JSX in React Components.

September 12, 2026 7 min read

What is JSX

  • JSX → JavaScript XML
  • It allows us to write HTML with React.
  • It makes it easier to write HTML in React.

Coding JSX

JSX allows us to write HTML elements in JS and place them in DOM without any function like createElement() or appendChild().

It converts HTML element into React element.

Example 

const myElement = <h1>I Love JSX!</h1>;

    createRoot(document.getElementById("root")).render(
        myElement
    );

Expression in JSX

We can write expression within { }.

The expression can be a React variable, property or any valid JS expression.

JSX will execute the expression and return the result.

Example 

const myElement =
        <h1>React is {5 + 5} times better with JSX</h1>;

Inserting a Large Block of HTML

To write HTML on multiple lines, put HTML inside parentheses.

Example 

const myElement = (
        <ul>
            <li>Apples</li>
            <li>Bananas</li>
            <li>Cherries</li>
        </ul>
    );

One Top Level Element

The HTML code must be wrapped in one top level element.

So, if we write two paragraphs, we must put them inside a parent element like <div>.

Example 

const myElement = (
        <div>
            <p>I am a paragraph.</p>
            <p>I am a paragraph too.</p>
        </div>
    );

JSX will throw an error if the HTML is not correct or if HTML misses parent element.

Fragment

Alternatively, we can use "fragment" to wrap multiple lines.

Fragment: <> </>

Example 

const myElement = (
        <>
            <p>I am a paragraph.</p>
            <p>I am a paragraph too.</p>
        </>
    );

Elements Must be Closed

JSX follows XML rules and therefore HTML elements must be properly closed.

Example 

const myElement = <input type="text" />;

JSX will throw an error if the HTML is not properly closed.

Attribute class = className

The class attribute is much used in HTML, but since JSX is rendered as JS, the class keyword is a reserved keyword and cannot be used in JSX.

We use className instead of class.

Example 

const myElement =
        <h1 className="myclass">Hello World</h1>;

JSX in React Components

React use components to build UI.

The components are independent and reusable.

React component are like JS function and return HTML.

JSX work perfect inside React components.

Example 

function Car() {
        return (
            <>
                <h2>My Car</h2>
                <p>It is a Ford Mustang.</p>
            </>
        );
    }

    createRoot(document.getElementById("root")).render(
        <Car />
    );

Operations Inside Components

Inside the components, we can do some other operations before returning HTML.

Example 

function Car() {

        const brand = "Ford";
        const model = "Mustang";

        return (
            <>
                <h2>My Car</h2>
                <p>It is a {brand} {model}.</p>
            </>
        );
    }

    createRoot(document.getElementById("root")).render(
        <Car />
    );
