React ES6 - Destructuring

Understand ES6 destructuring for arrays and objects, default values, nested objects, props destructuring, and useState hook destructuring in React.

September 04, 2026 7 min read

Destructuring makes the code shorter and more readable by reducing repetitive object and array access.

Destructuring Arrays

Old Way 

const ve = ["mustang", "F150", "expedition"];

const car = ve[0];
const truck = ve[1];
const suv = ve[2];

document.getElementById("demo").innerHTML = truck;

New Way 

const ve = ["mustang", "F150", "expedition"];

const [car, truck, suv] = ve;

document.getElementById("demo").innerHTML = truck;

When destructuring arrays, the order that variables are declared is important.

Destructuring Objects

We can use destructuring to extract values from an object.

Example 

const person = {
    FN: "John",
    LN: "Doe",
    age: 50
};

let { FN, age, LN } = person;

document.getElementById("demo").innerHTML =
    FN + LN + age;
  • We can unpack the values in random order.
  • We can extract the value what we want.

Default Value

We can set default value for the missing property. 

const person = {
    FN: "John",
    LN: "Doe",
    age: 20
};

let {
    FN,
    LN,
    age,
    country = "India"
} = person;

Destructuring Nested Objects

We can also destructure a nested object by referencing the nested objects using curly braces.

Example 

const person = {
    FN: "John",
    LN: "Doe",
    age: 50,
    car: {
        brand: "Ford",
        model: "Mustang"
    }
};

// Destructuring
let {
    FN,
    LN,
    age,
    car: {
        brand,
        model
    }
} = person;

let msg =
    "My name is " + FN +
    " and I have a " + brand +
    " " + model;

Destructuring in React Components

It is particularly useful in React for working with props, hooks, and API responses.

It helps to make our code more concise & easier to read.

Props Destructuring

When a component receives props, we can use destructuring to extract values we need.

Example

Using destructuring: 

function Greeting({name, age}) {

    return (
        <h1>Hello, {name}! You are {age} years old</h1>
    );

}

Not using destructuring: 

function Greeting(Props) {

    return (
        <h1>Hello, {Props.name}! You are {Props.age} years old</h1>
    );

}

Example 

import { createRoot } from "react-dom/client";

function Greeting({name, age}) {

    return (
        <h1>Hello, {name}! You are {age} years old</h1>
    );

}

createRoot(document.getElementById("root")).render(
    <Greeting name="John" age={20} />
);

useState Hook Destructuring

When a component uses the useState hook, we use destructuring to extract values from it.

Example 

import { createRoot, useState } from "react-dom/client";

function Counter() {

    //destructuring array by useState
    const [count, setCount] = useState(0);

    return (
        <button onClick={() => setCount(count + 1)}>
            Count: {count}
        </button>
    );

}

createRoot(document.getElementById("root")).render(
    <Counter />
);
